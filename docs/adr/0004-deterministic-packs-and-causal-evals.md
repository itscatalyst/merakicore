# ADR 0004: Deterministic packs and causal evaluation

Status: accepted

Packs use RFC 8785 canonical JSON, SHA-256, explicit policy/renderer versions, and stable atom-version tie-breaking. Improvement claims require frozen baseline, equal-token raw-memory, Meraki, and targeted-ablation arms; reviewer blinding; reported failures/ties/abstentions; and related-change/unrelated-invariance evidence.
